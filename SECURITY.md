# Учётные данные и файлы релиза

Не коммитьте рабочие конфигурации роутера, ссылки CSQTT/подписок, VK-токены,
GitHub-токены, SSH-ключи и резервные копии. Для примеров используйте
`test.invalid` и явно фиктивные значения. При утечке замените учётные данные:
одного удаления файла из текущей ветки недостаточно.

Зашифрованная CSQTT-ссылка тоже содержит секреты. Формат совместимости
использует общую константу шифрования из upstream; это не персональный
ключ владельца и не гарантия сокрытия параметров от обладателя исходников.
Храните ссылки обоих форматов как пароли.

Перед публикацией проверьте историю Git, отслеживаемые файлы, содержимое APK
и файлы GitHub Release. Кэши анализа и инструменты разработчика не входят в релиз.
Для установки используйте официальные ссылки этого репозитория и сверяйте
пакеты с `SHA256SUMS`.
