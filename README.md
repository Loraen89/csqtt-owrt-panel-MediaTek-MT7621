# CSQTT-PANEL v2.0

**CSQTT-PANEL v2.0** — панель управления LuCI и комплект клиентских ядер для
развёртывания **CSQTT-туннеля** на роутерах. CSQTT использует инфраструктуру
VK/Одноклассников для передачи трафика, в том числе в условиях сетевых ограничений
и «белых списков». Доступность зависит от сервера, оператора и выбранного транспорта.

Эта сборка предназначена для **MediaTek MT7621** и архитектуры `mipsel_24kc`.
Поддерживаются два целевых релиза OpenWrt:
**25.12.x** (пакеты `*.apk`, менеджер `apk`) и **24.10.x** (пакеты `*.ipk`, менеджер `opkg`).
Целевые устройства — Xiaomi Mi Router 3G и Netis N6 v1.

> ⚠️ **2.0-r14 — БЕЗ ИСПЫТАНИЙ НА РОУТЕРЕ.**
> Эта версия не проверялась на физическом MT7621, в QEMU и нативном ucode.
> Публикуется как предварительный выпуск `v2.0-mt7621-r14-rc1`.
> Реальный туннель, Gooby, CAPTCHA и сетевое восстановление не проверены.
> Перед установкой сохраните резервную копию. Проверки прошлых версий
> не подтверждают работу r14. [Описание и установка выпуска](docs/RELEASE-r14.md).

**Ядро и первоисточник:** [amurcanov/csqtt](https://github.com/amurcanov/csqtt).
Этот репозиторий содержит адаптацию панели и упаковку для OpenWrt/MT7621;
авторство ядра не меняется. Подробности — [NOTICE.md](NOTICE.md).

## Предварительный выпуск 2.0-r14: три ядра

Панель поддерживает **2.1.9, 2.5.1 и 2.5.3** одновременно. Версия выбирается
явно в редакторе профиля и при импорте; шифрование ссылки не определяет протокол
сервера. Старое значение UCI `2.5.0` остаётся алиасом **2.5.1**, а `auto`
выбирает установленное ядро в порядке 2.5.3 → 2.5.1 → 2.1.9.
При явном выборе отсутствующего ядра подмены другой версией нет.

Для установки локально собранного кандидата скачайте `dist/` и
`install-csqtt.sh` одной версии, затем на роутере:

```sh
ash install-csqtt.sh --core all
# Или только панель и конкретное ядро:
ash install-csqtt.sh --core 2.5.3
```

`--core both` сохраняет прежний смысл: 2.1.9 + 2.5.1. Для трёх ядер нужен
`--core all`. Выпуск опубликован как [v2.0-mt7621-r14-rc1](https://github.com/Loraen89/csqtt-owrt-panel-MediaTek-MT7621/releases/tag/v2.0-mt7621-r14-rc1)
с пометкой «БЕЗ ИСПЫТАНИЙ НА РОУТЕРЕ». Обычная установка Latest продолжает
использовать стабильный выпуск. Команда установки именно r14 — в [описании выпуска](docs/RELEASE-r14.md).

Поддерживаются ссылки CSQTTR с `power`, `hashes` и `token`.
Хеши и токен сохраняются в импортируемом профиле; общие VK-настройки не заменяются
без выбора соответствующей опции. VK-токен не включается в экспорт автоматически.
В редакторе профиля доступны потоки, транспорт, OBFS, SRTP и индивидуальный режим VK.
Gooby включается только для 2.5.3 при TURN TCP/TLS.

Ядро 2.5.3 и его supervisor взяты из проверенного пакета starkugz для MT7621;
бинарники не изменены. Это динамическая MIPS-сборка: нужны `libc`, `libgcc1`
и `kmod-tun`. Управление адаптировано к единственному выбранному профилю;
переход между разными ядрами выполняется панелью при перезапуске службы.
Подробнее: [источники и ограничения r14](docs/UPSTREAM-r14.md).

**r14 не проверен на физическом MT7621 и в QEMU. Реальный VK/TURN-туннель,
Gooby, CAPTCHA и сетевое восстановление 2.5.3 этой сборки не проверены.**

## Основные возможности

- **Управление профилями в LuCI:** импорт открытых и зашифрованных ссылок `csqtt://`,
  выбор сервера и сохранение настроек в UCI.
- **Три ядра для MT7621:** 2.1.9, 2.5.1 и 2.5.3 в отдельных APK/IPK;
  ядро явно выбирается и сохраняется в профиле. Перед установкой проверяется SHA256.
- **Параметры туннеля:** количество воркеров, транспорт TURN UDP/TCP, режимы
  обфускации и MTU. Транспорт по умолчанию — UDP.
- **Управление службой через procd:** запуск, остановка, автозапуск и восстановление
  процесса после завершения; ожидание доступного IPv4-маршрута при старте.
- **Состояние и диагностика:** активные воркеры, трафик, CPU и RSS процесса,
  журналы и ручная проверка HTTPS через туннель.
- **Связка с SSClash/Mihomo:** интерфейс `csqtt0` используется как выход для
  выбранного прокси-трафика. Правила маршрутизации и резервирования настраиваются
  в самом прокси-клиенте.

Описание возможностей адаптировано из [csqtt-owrt-panel](https://github.com/Loraen89/csqtt-owrt-panel)
с учётом реализации этой сборки для MT7621.

## Установка из репозитория

Публичные файлы можно скачать без GitHub-аккаунта и токена. Команды выполняются
**по SSH на роутере** с доступом в интернет. Установщик сам определяет пакетный
менеджер устройства (`apk` для OpenWrt 25.12.x, `opkg` для OpenWrt 24.10.x) и
берёт соответствующий набор пакетов из одного релиза.

### Установка на OpenWrt 25.12.x (apk)

```sh
apk add curl ca-bundle
curl -fsSL -o /tmp/install-from-github.sh \
  https://raw.githubusercontent.com/Loraen89/csqtt-owrt-panel-MediaTek-MT7621/main/install-from-github.sh
ash /tmp/install-from-github.sh --core both
```

### Установка на OpenWrt 24.10.x (opkg)

```sh
opkg update
opkg install curl ca-bundle
curl -fsSL -o /tmp/install-from-github.sh \
  https://raw.githubusercontent.com/Loraen89/csqtt-owrt-panel-MediaTek-MT7621/main/install-from-github.sh
ash /tmp/install-from-github.sh --core both
```

### Проверенный кандидат r10-rc1 (только 25.12.x)

```sh
apk add curl ca-bundle
curl -fsSL -o /tmp/install-from-github.sh \
  https://raw.githubusercontent.com/Loraen89/csqtt-owrt-panel-MediaTek-MT7621/main/install-from-github.sh
ash /tmp/install-from-github.sh --core both --ref v2.0-mt7621-r10-rc1
```

Это **prerelease**, исправляющий найденные ошибки r9. Результаты и ограничения:
[AUDIT.md](AUDIT.md). Программа проверяет SHA256 каждого выбранного APK перед установкой.
Профили сохраняются; настроенные WAN, LAN, Wi-Fi, DHCP и SSClash установщик не меняет.
Сохраните свою резервную копию перед обновлением.

### Последний стабильный GitHub Release

Без `--ref` установщик выбирает GitHub Latest — сейчас это r9, который не содержит
исправлений кандидата r10-rc1:

```sh
ash /tmp/install-from-github.sh --core both
```

Вместо `both` можно указать `2.1.9` или `2.5.0` для установки только одного ядра.
Ветка 2.5.0 использует исправленный бинарник **2.5.1**.
Для приватных зеркал поддерживается необязательная переменная `GITHUB_TOKEN`
с разрешением Contents: read; в публичном репозитории она не нужна.

### Ручная установка пакетов

Скачайте пакеты (`*.apk` для OpenWrt 25.12.x или `*.ipk` для OpenWrt 24.10.x),
`SHA256SUMS` и `install-csqtt.sh` из одного выпуска в общую папку
`/tmp/csqtt` на роутере. Для двух ядер нужны все три пакета, для одного — панель
и выбранное ядро:

```sh
cd /tmp/csqtt
ash install-csqtt.sh --core both
```

Скрипт сам выберет `*.apk` (OpenWrt 25.12.x) или `*.ipk` (OpenWrt 24.10.x)
по доступному пакетному менеджеру.

## Совместимость с прокси-клиентами

Работает в связке с **SSClash** — проверено с SSClash v4/Mihomo — и аналогичными
прокси-клиентами, которые умеют использовать интерфейс **csqtt0** как выход в сеть.
Панель поднимает CSQTT-туннель, а SSClash или другой клиент выбирает, какой трафик
направлять через него. Сам SSClash, другие прокси-клиенты и подписки в пакет не входят.

| `csqtt-core-2.5.3-openwrt-25.12-mipsel_24kc.apk` | Ядро 2.5.3 и supervisor для OpenWrt 25.12.x |
| `luci-app-csqtt-2.0-openwrt-24.10.ipk` | Панель CSQTT-PANEL v2.0 для OpenWrt 24.10.x |
| `csqtt-core-2.1.9-openwrt-24.10-mipsel_24kc.ipk` | Ядро 2.1.9 для OpenWrt 24.10.x |
| `csqtt-core-2.5.1-openwrt-24.10-mipsel_24kc.ipk` | Ядро 2.5.1 для OpenWrt 24.10.x; имя пакета `csqtt-core-2.5.0` |
| `csqtt-core-2.5.3-openwrt-24.10-mipsel_24kc.ipk` | Ядро 2.5.3 и supervisor для OpenWrt 24.10.x |

Откройте **LuCI → Службы → CSQTT-PANEL v2.0 → Профили** и импортируйте ссылку.

- При импорте открытой или зашифрованной ссылки выберите ядро, соответствующее серверу.
- Транспорт TURN по умолчанию — **UDP**; TCP можно выбрать вручную.
- Общие параметры VK находятся на странице **Туннель и VK**.
- Для одновременных клиентов одного сервера нужны отдельные серверные профили
  с уникальными адресами туннеля.
- Экспорт 2.1.9 работает по HTTP; зашифрованный экспорт 2.5.1 требует HTTPS/WebCrypto.

Ссылки CSQTT, VK-токены и подписки содержат секреты — не публикуйте их.
Ограничения формата шифрования ссылок описаны в [SECURITY.md](SECURITY.md).

## Сборка и проверка

Исходники прежних ядер: `core219/` и `core251/`; импорт 2.5.3 описан в `docs/UPSTREAM-r14.md`. Для пересборки нужны Rust, Zig и musl runtime
из OpenWrt SDK. Скрипты принимают путь к установленным инструментам:
```powershell
powershell -File core219/build-mips.ps1 -Jobs 4 -ToolingPath D:/csqtt-tooling
powershell -File core251/build-mips.ps1 -Jobs 4 -ToolingPath D:/csqtt-tooling
```

Первую сборку с загрузкой зависимостей выполняйте с `-Online`. После появления бинарников в `core219/dist/` и `core251/dist/` сборщик создаст восемь пакетов — по четыре для OpenWrt 25.12.x (`*.apk`) и 24.10.x (`*.ipk`):

```sh
node tools/prepare-cores.mjs
node luci-app-csqtt/build-package.mjs
node tools/verify-panel.mjs
node tools/test-export.mjs
node tools/test-logs.mjs
```

Бэкап и порядок аппаратной проверки: [docs/HARDWARE.md](docs/HARDWARE.md).
Перед установкой выполните `node tools/backup-router.mjs 192.168.7.1` из локального
терминала с доступом к роутеру и убедитесь, что `manifest.json` содержит `complete: true`.

Проверка на роутере:

```sh
/usr/libexec/csqtt/csqtt-core-2.1.9 --self-test
/usr/libexec/csqtt/csqtt-core-2.5.0 --self-test
ubus call csqtt access_check
```
