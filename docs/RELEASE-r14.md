# CSQTT-PANEL r14 — БЕЗ ИСПЫТАНИЙ НА РОУТЕРЕ

> **Этот выпуск не проходил испытаний на физическом роутере.**
> Работа на Xiaomi Mi Router 3G, Netis N6 v1 и других MT7621 этой сборкой
> не подтверждена. Публикуется как **предварительный выпуск**.

Панель поддерживает выбор ядер **2.1.9 / 2.5.1 / 2.5.3** для MT7621
(`mipsel_24kc`), пакеты APK для OpenWrt 25.12.x и IPK для OpenWrt 24.10.x.

## Что изменилось

- Явный выбор ядра в профиле и при импорте. UCI-алиас `2.5.0` сохраняет
  прежнее значение — ядро 2.5.1. Выбранное отсутствующее ядро не подменяется.
- Отдельная поставка 2.5.3 с транспортом и supervisor из starkugz v2.5.3.
  Бинарники не изменены; исходный пакет проверен по фиксированной SHA-256.
- Исправлены импорт `power`, `hashes`, `token`, экспорт адреса/порта и хешей.
  VK-токен импортируемого профиля не заменяет общий аккаунт.
- Добавлены профильные настройки потоков, транспорта, OBFS, SRTP и VK;
  Gooby доступен для 2.5.3 при TURN TCP/TLS.
- Установщики поддерживают `--core all` и `--core 2.5.3`.
  `--core both` сохраняет прежнюю пару 2.1.9 + 2.5.1.
- Исправлены ar-заголовки IPK и установка локальных APK через apk-tools 3.

## Установка именно этого выпуска

Команды выполняются по SSH на роутере. Для OpenWrt 25.12.x сначала:

```sh
apk add curl ca-bundle
```

Для OpenWrt 24.10.x вместо этого:

```sh
opkg update
opkg install curl ca-bundle
```

Затем скачайте установщик закреплённой версии и установите три ядра с панелью:

```sh
curl -fsSL -o /tmp/install-from-github.sh \
  https://raw.githubusercontent.com/Loraen89/csqtt-owrt-panel-MediaTek-MT7621/v2.0-mt7621-r14-rc1/install-from-github.sh
ash /tmp/install-from-github.sh --core all --ref v2.0-mt7621-r14-rc1
```

Вместо `all` можно выбрать `2.1.9`, `2.5.1` или `2.5.3`.
Версию ядра сервера укажите явно в профиле. Шифрование ссылки её не определяет.
Установщик проверяет SHA-256 выбранных пакетов. Выпуск имеет статус prerelease;
обычный GitHub Latest продолжает указывать на стабильный выпуск.

## Выполненные проверки и ограничения

Пройдены локальные тесты ссылок, редактора/импорта профилей, выбора CLI трёх
ядер, изоляции и очистки UCI-снимка 2.5.3, планов установки APK/IPK, журналов,
бэкапа, структуры и контрольных сумм пакетов. Упаковка воспроизводима при LF/CRLF.

**Не выполнялись испытания r14 на физическом MT7621, в QEMU и нативном ucode.**
Реальный VK/TURN-туннель, передача трафика, Gooby, CAPTCHA, Flood control
и восстановление после сетевых сбоев не проверены. Предпросмотр интерфейса
использует демонстрационные данные и не является испытанием на роутере.

Динамическое MIPS-ядро 2.5.3 требует `libc`, `libgcc1`, `kmod-tun`;
совместимость с библиотеками конкретного роутера ещё не подтверждена.
Перед установкой сохраните резервную копию конфигурации и пакеты прежней версии.
