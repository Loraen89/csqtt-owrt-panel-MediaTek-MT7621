# LuCI-панель CSQTT 2.0-r3

Версия `2.0-r3` исправляет переносимость APK, собранного в Windows, и
документирует проверку на реальном Netis N6 v1.

## Исправлено

- `build-package.mjs` нормализует окончания строк в `/etc/init.d/csqtt` и
  `/usr/libexec/csqtt/run-core.sh` в LF перед упаковкой APK;
- добавлен `.gitattributes`, фиксирующий LF для shell-скриптов и init-файлов;
- версия пакета панели повышена до `2.0-r3`.

Без нормализации OpenWrt интерпретировал первую строку init-скрипта как
`#!/bin/sh\r` и завершал запуск ошибкой `/etc/rc.common\r: not found`.

## Проверка на устройстве

Проверено на Netis N6 v1 (`netis,n6`, `ramips/mt7621`) с OpenWrt 25.12.5:

- локальная установка панели и обоих ядер через `--core both`;
- запуск procd-службы с `core_version=auto`;
- выбор бинарника 2.5.1 и создание интерфейса `csqtt0`;
- наличие обоих пакетов ядра 2.1.9 и 2.5.0/2.5.1;
- работа LuCI, RPC и веб-терминала после установки.

APK по-прежнему не требует добавления стороннего ключа: установщик сверяет
SHA256 и использует `apk add --allow-untrusted` только для уже проверенного
локального файла.
