# LuCI-панель CSQTT 2.0-r6

Версия `2.0-r6` изменяет только визуальное представление состояний на странице
«Статус» и не меняет UCI, RPC, init-скрипт или работу ядер.

- У индикаторов убраны рамки, скругления, фон и внутренние отступы.
- Положительные состояния выводятся зелёным полужирным текстом; предупреждения,
  ошибки и информационные состояния сохраняют соответствующие цвета.
- Первая буква статуса приводится к верхнему регистру.
- Увеличены межстрочный и вертикальный интервалы блока индикаторов.

Сборка предназначена сначала для локальной QEMU-проверки, затем для установки
поверх `2.0-r5` без замены `/etc/config/csqtt`.
