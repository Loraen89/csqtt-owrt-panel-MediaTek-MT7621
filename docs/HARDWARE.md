# Проверка на Netis N6

Следующий этап после QEMU — бэкап и тесты на физическом MT7621.
**Тесты на физическом роутере именно версии 2.0-r13 не проводились.**

Отчёт предыдущего локального прогона QEMU находится в
[QEMU-REPORT-2026-11-18.md](QEMU-REPORT-2026-11-18.md): 116 проверок прошли,
но физическая плата, реальный туннель и VK Flood control там не проверялись.

## Бэкап перед установкой

Из корня проекта, в локальном терминале с доступом к сети роутера:

```powershell
node tools/backup-router.mjs 192.168.7.1
```

Нужны Node.js и OpenSSH (`ssh`). Подключение — `root`, без интерактивного
запроса пароля. Используется отдельный `backups/known_hosts`: первый ключ
сохраняется, изменение известного ключа блокирует подключение.

Сценарий проверяет OpenWrt `ramips/mt7621`, сохраняет сведения о плате,
разделах и пакетах, архив `sysupgrade -b`, затем каждый доступный MTD-раздел.
Бинарные данные передаются напрямую в файл, без текстового преобразования
PowerShell. Для NOR применяется `dd`; для NAND нужен установленный `nanddump`
с поддержкой `--bb=padbad`, `--omitoob`, `--length`. При отсутствии этих
возможностей сценарий завершится с ошибкой. Пакеты автоматически не устанавливаются.

Для каждой копии проверяются размер и SHA-256 второго чтения с роутера.
Активная запись во flash между чтениями может привести к несовпадению:
такой результат считается незавершённым, проверку нельзя обходить.
Сценарий не останавливает службы и не меняет настройки; на роутере создаётся
только временный архив конфигурации в `/tmp`, который затем удаляется.

Результаты находятся в `backups/<адрес>-<время UTC>/`. Успех подтверждается
кодом возврата 0 и `complete: true` в `manifest.json`. При ошибке остаётся
`complete: false`, причина ошибки и, возможно, файлы `.partial`.
До успешного завершения бэкапа к установке переходить нельзя.
Каталог `backups/` исключён из публикации через `.gitignore` и содержит секреты.

Это копии всех **доступных логических MTD-разделов**, включая загрузчик и
калибровки, если прошивка предоставляет их как MTD. NAND сохраняется после ECC,
с заполнением плохих блоков и без OOB. Это не сырой дамп NAND для программатора;
скрытые области flash не читаются. Восстановление загрузчика, калибровок и UBI
требует отдельного плана для конкретной разметки и не выполняется этим сценарием.

## Порядок аппаратной проверки

1. Проверить модель и ревизию из `board.json`, версию OpenWrt, свободную RAM/flash,
   наличие `tun`, доступность зависимостей и успешный манифест бэкапа.
2. Проверить `dist/SHA256SUMS`; выбрать IPK для 24.10 либо APK для 25.12.
   Установить панель и оба ядра с проверкой зависимостей, без принудительного
   игнорирования несовместимости. Сохранить исходные настройки и автозапуск CSQTT.
3. Проверить вход в LuCI, регистрацию `ubus list csqtt`, RPC status и оба self-test.
   Self-test выполнять при остановленной CSQTT, чтобы исключить конфликт TUN.
4. На тестовом профиле поочерёдно проверить 2.1.9 и 2.5.1: старт, создание TUN,
   реальный трафик, смену ядра, остановку и удаление TUN. Использовать настоящие
   учётные данные только локально; не помещать ссылки и токены в отчёт.
5. Проверить восстановление через procd после завершения процесса, затем
   длительную нагрузку с замерами RSS/CPU и проверкой OOM/сбоев ядра.
6. Проверить отображение VK Flood control, ожидание и автоматическое восстановление
   при имеющемся ограничении; не провоцировать ограничение шквалом запросов.
   Если ограничения нет, отметить эту проверку как невыполненную.
7. Проверить восстановление исходного профиля, автозапуска и доступности управления.
   Сохранить отчёт с длительностью, результатами и хешами установленных пакетов.
   Текущая версия опубликована без аппаратной проверки с явной пометкой об этом;
   результаты будущей проверки нужно отнести к точной ревизии и хешам пакетов.

## Проверка сценария без роутера

```powershell
node --test tools/test-backup.mjs
```

Тесты проверяют разбор разделов, команды NAND, размеры и хеши, передачу всех
значений байтов, ненулевой код команды и тайм-аут. Они не подтверждают чтение
flash физического устройства.
