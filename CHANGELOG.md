# Изменения

## 2.0-r11

**Не проверялся на роутерах.** Выпуск проверен статически: структура пакетов,
контрольные суммы, воспроизводимость сборки, синтаксис скриптов и песочница
установщиков. Работа на реальном устройстве с OpenWrt 24.10.x не подтверждена.

- Добавлена поддержка **OpenWrt 24.10.x**: в `dist/` появились IPK-пакеты
  (`luci-app-csqtt-2.0-openwrt-24.10.ipk` и два `csqtt-core-*-openwrt-24.10-mipsel_24kc.ipk`)
  для пакетного менеджера `opkg`. APK-набор для OpenWrt 25.12.x не меняется.
- `build-package.mjs` теперь собирает шесть пакетов: три APK и три IPK;
  `SHA256SUMS` содержит контрольные суммы всех шести.
- IPK панели: `Architecture: all`, `/etc/config/csqtt` объявлен как conffile,
  скрипты `postinst`/`prerm`/`postrm` повторяют поведение APK-lifecycle:
  автозапуск службы при новой установке, его сохранение при обновлении
  (состояние запоминается в `/var/run/csqtt-autostart-flag`), остановка службы
  перед удалением/обновлением, очистка кеша LuCI и перезапуск `rpcd`.
- Установщики `install-csqtt.sh`, `install-from-github.sh` и `uninstall-csqtt.sh`
  автоматически определяют пакетный менеджер (`apk` или `opkg`) и выбирают
  соответствующий набор имён пакетов. Перед установкой на 24.10.x рекомендуется
  выполнить `opkg update`.
- Очистка кеша LuCI переведена на `rm -rf /tmp/luci-indexcache*`, что корректно
  для обеих веток OpenWrt (в 24.10 имя каталога кеша отличается).
- `.github/workflows/release.yml` публикует все шесть пакетов в одном релизе.

## 2.0-r10 — кандидат r10-rc1

- Исправлены протокол экспорта, приватность диагностики, старый статус после respawn и выбор неполного профиля.
- Восстановлены журналы ядра, статус auto_js и отображение фактического адреса туннеля; обычные stderr-сообщения больше не попадают в категорию ошибок только из-за daemon.err.
- Усилены проверка контрольных сумм и обработка ошибок удаления; обновление сохраняет автозапуск.
- Упаковка воспроизводима при LF/CRLF, лицензии включены в APK.
- Добавлены регрессионные тесты; подробности в AUDIT.md.


## 2.0-r9

- CPU и RSS процесса CSQTT считываются из /proc для обоих ядер, включая 2.1.9.
- CPU нормирован к одному логическому ядру; 100% означает полную загрузку одного ядра.
- При перезапуске процесса замер CPU начинается заново, устаревшие значения не показываются.


## 2.0-r8

- Наименование панели, меню и документации изменено на **CSQTT-PANEL v2.0**.
- Сохранены исправленная навигация, выбор ядра по профилю и UDP по умолчанию.

## 2.0-r7

- Название панели: **CSQTT-PANEL v2.0** во всех страницах и меню LuCI.
- Исправлена ссылка из «Профилей» в «Туннель и VK»: используется маршрут LuCI вместо URL-фрагмента.
- Сохранены UDP по умолчанию и автоматический выбор ядра по типу ссылки.
- Проверка HTTPS ожидает соединение до 10 секунд и повторяется один раз при временной ошибке; таймаут интерфейса согласован с backend.
- Удалены снимки состояния конкретных роутеров, разовые диагностические скрипты и устаревшие отчёты. Проверка APK вынесена в `tools/verify-panel.mjs`.
- Инструкция установки сокращена; лицензии, исходники и файлы сборки сохранены.
